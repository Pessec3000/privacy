Политика конфиденциальности / Privacy Policy

Приложение «GWS» (персональный помощник Hermes). Редакция от 26.10.2026.

Что это за приложение

GWS — частный помощник для личного использования владельцем Google-аккаунта. Он не предназначен для посторонних пользователей и не распространяется публично.

Какие данные используются

С согласия владельца приложение получает доступ к разрешённым сервисам Google (Календарь, Почта, Диск и т. п.) только для задач, которые владелец сам поручил помощнику: показать события, найти письмо или файл, поставить напоминание.

Чего приложение не делает

Данные не продаются, не передаются третьим лицам, не используются для рекламы и не применяются для обучения моделей. Использование и передача информации, полученной через API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Хранение и отзыв доступа

Токены доступа хранятся на сервере владельца, к которому нет доступа у посторонних. Отозвать доступ можно в любой момент на myaccount.google.com/permissions; после этого токены удаляются.
